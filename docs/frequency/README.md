# موضوع: مدیریت فرکانس (Frequency Manager)

منبع خارجی پیش‌فرض برای واکشی: **LyngSat** (نام محصول نیست).

## کد

- اپ: [`../../spidervip/frequency/`](../../spidervip/frequency/) — محصول UI: **مدیریت فرکانس**

- جایگاه آینده: تب/فضای کار داخل **SpiderVIP Console**
