**فایل:** `SPIDER-VIP_v1.00.92_20260507.mupg`
**حجم:** 530,280,116 بایت (505.7 MB)
**چیپست:** HiSilicon **Hi3798M V300** (ARM Cortex-A53, DVB STB SoC)
**RAM:** 1GB DDR3 | **Flash:** 8GB (eMMC/NAND) | **تاریخ ساخت:** 2026/05/07 09:57:25

## ۱. ساختار کلی فایل `.mupg`

فایل یک کانتینر آپگرید اختصاصی HiSilicon است با این چیدمان:

```
┌────────────────────────────────────────────────────────┐
│ 0x000  Main Header (96 B)  → نوع، محصول، نسخه، چیپست     │
│ 0x400  Info Header         → timestamp + تکرار متادیتا   │
│ 0x805  Partition Table     → 10 ورودی × 36 بایت          │
│ ....   Image Data          → داده هر پارتیشن پشت سر هم    │
└────────────────────────────────────────────────────────┘
```

### هدر اصلی (offset 0x00)
| offset | مقدار | توضیح |
|--------|-------|-------|
| 0x04 | `all` | نوع آپگرید (کامل) |
| 0x08 | `SPIDER_VIP` | نام محصول |
| 0x28 | `1.00.92` | نسخه فریمویر |
| 0x34 | `3798MV300` | چیپست |
| 0x40 | `DDR 1GB` / `TOP 8GB` | مشخصات سخت‌افزار |
| 0x50 | `1F 9B 6A B4` | Checksum کل فایل |

## ۲. جدول پارتیشن (offset 0x805، هر ورودی 36 بایت)

ساختار هر ورودی:
```
[0..19]  name          نام (ASCII، null-padded)
[20..23] part_size     اندازه رزرو روی فلش      (Big-Endian)
[24..27] img_len       طول واقعی داده image     (Big-Endian)
[28..31] flash_offset  آدرس شروع روی فلش         (Big-Endian)
[32..35] flags         پرچم/رزرو                (Big-Endian)
```

| # | نام | اندازه پارتیشن | داده واقعی | آدرس فلش | نوع محتوا |
|---|------|----------------|-----------|----------|-----------|
| 0 | fastboot   | 1.0 MB   | 942 KB   | 0x00000000 | U-Boot / fastboot (bootloader) |
| 1 | bootargs   | 1.0 MB   | 64 KB    | 0x00100000 | آرگومان‌های بوت کرنل |
| 2 | baseparam  | 1.0 MB   | 5.7 KB   | 0x00200000 | پارامترهای پایه (صفحه/HDMI) |
| 3 | pqparam    | 1.0 MB   | 170 KB   | 0x00300000 | پارامترهای کیفیت تصویر (PQ) |
| 4 | logo       | 1.0 MB   | 600 KB   | 0x00400000 | لوگو بوت |

## ۳. یافته‌های اسکن امضا

- **kernel:** uImage (U-Boot legacy) در آدرس ~0x1BEAE8
- **rootfs:** فشرده‌سازی احتمالی SquashFS/UBIFS + gzip/lzma
- **DTB:** ۶ عدد Device Tree Blob
- بخش loader شامل رشته‌های U-Boot نسخه `3.3.0` و درایورهای MCI/OTP/NAND

---

## ۴. جایگاه «برنامه» رسیور

«برنامه‌ای» که کاربر با آن کار می‌کند (منو، EPG، پخش کانال، تنظیمات) داخل پارتیشن
**rootfs** (شماره 8) به صورت باینری‌های ARM ELF کامپایل‌شده قرار دارد.
تحلیل باگ و memory leak **فقط** با استخراج این پارتیشن و مهندسی معکوس آن باینری‌ها ممکن است
— نه از روی ساختار کانتینر. (توضیح کامل در بخش پاسخ به سؤالات).
