# راهنمای دسترسی شبکه‌ای به رسیور (Enigma2) و خواندن رم واقعی

این رسیور یک دستگاه **Enigma2** است و طبق فایل‌سیستمش، سرویس‌های زیر هنگام روشن‌شدن **خودکار فعال** می‌شوند:
- **Telnet** روی پورت 23  (`/usr/sbin/telnetd`)
- **FTP** روی پورت 21   (`vsftpd`)
- احتمالاً **وب (OpenWebif)** روی پورت 80

پس بدون هیچ فلشی می‌توانیم زنده وارد دستگاه شویم و رم واقعی را بخوانیم. **ریسک صفر.**

---

## گام ۱ — اتصال به شبکه و یافتن IP دستگاه
1. یک **کابل LAN** از مودم/روتر به پشت رسیور بزنید (یا اگر Wi-Fi دارد، در منو تنظیمش کنید).
2. روی رسیور با ریموت به مسیر زیر بروید تا IP را ببینید (بسته به تصویر کمی فرق دارد):
   - `Menu → Setup → System → Network → Network Adapter`  یا
   - `Menu → Information → Network`  یا
   - `Menu → اطلاعات → شبکه`
3. یک آدرس مثل `192.168.1.XX` می‌بینید. **آن را یادداشت کنید.**
   - اگر IP نگرفت، «DHCP» را روشن کنید یا کابل/روتر را چک کنید.

## گام ۲ — تست اینکه واقعاً شبکه/تلنت دارد (از روی همین کامپیوتر)
در PowerShell این‌ها را بزنید (به‌جای IP نمونه، IP خودتان):
```powershell
ping 192.168.1.XX
Test-NetConnection 192.168.1.XX -Port 23   # اگر TcpTestSucceeded=True → Telnet فعال است
Test-NetConnection 192.168.1.XX -Port 21   # FTP
Test-NetConnection 192.168.1.XX -Port 80   # وب (OpenWebif)
```

## گام ۳ — ورود با Telnet و خواندن رم واقعی (هدف اصلی)
اگر ویندوز شما telnet client ندارد، یک‌بار فعالش کنید:
```powershell
dism /online /Enable-Feature /FeatureName:TelnetClient
```
یا از PuTTY استفاده کنید (Connection type: **Telnet**, Port: 23).

سپس:
```
telnet 192.168.1.XX
login: root
Password: (رمز روت دستگاه)
```
> رمز روت: چون این دستگاه شخصی خودتان است، معمولاً یا رمزی که خودتان/فروشنده ست کرده، یا یکی از رمزهای پیش‌فرض رایج این تصاویر است. اگر رمز را نمی‌دانید، اغلب تصاویر Enigma2 اجازه می‌دهند از طریق منوی دستگاه رمز روت را تغییر دهید/بردارید.

بعد از ورود، این دستورها را بزنید و **خروجی را برای من کپی کنید**:
```sh
cat /proc/meminfo | head -3
free -m
cat /proc/cmdline
cat /proc/media-mem 2>/dev/null || cat /proc/umap/media-mem 2>/dev/null
uname -a
```
- `MemTotal` = رمی که لینوکس می‌بیند.
- مقدار MMZ/CMA در `media-mem` = رم رزروشده برای پردازش تصویر.
- **رم فیزیکی واقعی = MemTotal + رزرو MMZ.**

## گام ۴ (اختیاری) — بررسی اینکه فلش قبلی ما اصلاً اعمال شده بود یا نه
```sh
ls -l /data/raminfo.txt          # اگر وجود داشت → rootfs سفارشی ما فلش شده بود
cat /etc/version 2>/dev/null
cat /proc/version
```

## گام ۵ (اختیاری) — دسترسی گرافیکی وب
مرورگر را باز کنید: `http://192.168.1.XX`
اگر OpenWebif بالا بیاید، از همان‌جا هم می‌توانید System Info و حتی ترمینال داشته باشید.

---

## چرا این روش بهتر از فلش‌کردن است؟
- **ریسک صفر:** فقط خواندن؛ هیچ پارتیشنی بازنویسی نمی‌شود.
- روی Enigma2 می‌توان تغییرات را **زنده و برگشت‌پذیر** روی فایل‌ها اعمال کرد (از طریق FTP/Telnet)، به‌جای بازسازی کل mupg و ریسک نامعتبرشدن checksum.
- اگر خواستیم نمایش رم در منو را اضافه کنیم، روی Enigma2 این کار از طریق **پلاگین/اسکین پایتونی** انجام می‌شود (بسیار امن‌تر از patch باینری).

**قدم بعدی:** IP دستگاه و خروجی دستورهای گام ۳ را برایم بفرستید تا رم واقعی را قطعی تعیین کنیم و مسیر امنِ سفارشی‌سازی را بچینیم.
