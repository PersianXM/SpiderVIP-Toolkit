# SpiderVIP Toolkit — working rules

- **Versioning:** bump `spidervip/_version.py` on every user-facing change; see [`docs/conventions/VERSIONING.md`](docs/conventions/VERSIONING.md).
- **UI changes** in `spidervip/console/**`, `spidervip/frequency/**` and `spidervip/channels/static/**` follow [`docs/design/UI_RULES.md`](docs/design/UI_RULES.md). The design system and live tokens are indexed in [`docs/design/README.md`](docs/design/README.md).
- **Topics and docs:** [`docs/TOPICS.md`](docs/TOPICS.md) maps each topic to its code and its entry document.
- **Tests:** `python -m pytest -q`.
